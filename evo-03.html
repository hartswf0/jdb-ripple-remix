▾ How To Read RIPPLES INTRO
RIPPLES is a causal worldtext instrument. The goal is not only atmosphere. The goal is to make influence legible: what changed, where it moved, what resisted, and what evidence supports the prose.

Quick Start

1Select an entity in the field or Entity Pool.
2Trigger GOAL, OBSTACLE, or SHIFT.
3Read Impact Record first (source delta + transfer projections + non-effects).
4Read Worldtext as interpretation of the event, not the event itself.
5Use LLM Workbench to export a prompt bundle / JSON to any model.

What You Are Seeing

  • Impact Record: the structured ripple event (source, projected transfers, resistance, delays).
  • Worldtext: a perspective-layer narration generated from the event.
  • Audit Log: a trace of prior perturbations you can click to recall.

Parsing Rule

Read the system in this order: source delta → transfer channels → blocked paths → prose. If the prose implies a change not listed in the Impact Record, treat it as speculation.

Tip: the `content.js` console error usually comes from a browser extension content script, not this file. Test in an incognito window (extensions off) to confirm.
