Local Run Note

Some pages use fetch() and will behave better over a local HTTP server than opening files directly with file://. 

python3 -m http.server 8000

Then open http://localhost:8000/index.html.

Console Error Note

Errors like content.js:... Cannot read properties of undefined (reading 'query') are usually from a browser extension content script, not this repo. Test in an Incognito/private window with extensions off to confirm.

This repo's primary scripts are gpt.js, ripple-ai.js, and ripple-llm-adapter.js.
